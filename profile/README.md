# OWKR · 오버워치 한국 커뮤니티

함께 내전을 즐기고, 더 편하게 운영하기 위한 공간입니다. 참가 안내와 내전 규정부터
관리자 시험, 팀 편성 도구와 Discord 모집 봇까지 커뮤니티에 필요한 프로젝트를 만듭니다.

**[Discord 참여](https://discord.gg/overwatchkr) · [내전 규정](https://overwatch-kr.github.io/owkr-docs/) · [관리자 시험](https://owkr-exam.vercel.app)**

## 어디서 시작하나요?

- **내전 참가자** · [내전 규정과 FAQ](https://overwatch-kr.github.io/owkr-docs/)를 확인하고 Discord에서 모집에 참여하세요.
- **관리자 지원자** · 운영진의 응시 안내를 받은 뒤 [관리자 시험 웹](https://owkr-exam.vercel.app)에서 Discord 로그인과 응시 코드 입력을 진행하세요.
- **내전 관리자** · [OWKR Match](https://owkr-internal-balance.vercel.app/)에서 참가 명단과 팀 편성을 관리하세요. 접근에는 운영진 권한이 필요합니다.
- **개발 참여자** · 아래 저장소의 README에서 실행 방법과 프로젝트별 범위를 확인하세요.

## 내전 운영 흐름

내전 규정 확인 → Discord 모집·참가 → 티어 제출 → OWKR Match에서 팀 편성 → 경기 진행

각 도구는 이 흐름의 일부를 담당합니다. 봇의 모집·티어 수집과 웹의 팀 편성은 별도 프로젝트이며,
현재 자동 연동이 완료된 하나의 서비스로 제공되는 것은 아닙니다.

## 함께 만들기

기능 제안과 오류 제보는 해당 저장소의 **Issues**에 남겨 주세요.
내전 참가, 관리자 지원과 운영 문의는 [Discord](https://discord.gg/overwatchkr)에서 안내받을 수 있습니다.
기여 전에는 각 저장소의 README와 작업 지침을 확인해 주세요.
